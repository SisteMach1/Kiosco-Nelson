# Kiosco Nelson - Sistema Privado

Sistema completo de gestión para kiosco. 100% editable, offline, con clave privada.

**Dueño:** Nelson
**Clave:** Nelson2284
**Nombre del local:** Kiosco Nelson

## Funcionalidades
- Dashboard con ventas, ganancias, gastos, stock bajo
- Mercaderías con código de barras, costo, % ganancia, precio venta automático, descuento, aumento masivo
- Proveedores
- Punto de Venta (POS) con carrito, medios de pago, vuelto, ticket, descuento de stock
- Ganancias e informes diarios/semanales/mensuales
- Gastos
- Caja diaria (apertura/cierre)
- Fiados / Clientes
- Login privado con clave Nelson2284
- Logo personalizado y PWA instalable

## Como subir a GitHub
1. Crea un repo nuevo en github.com llamado `kiosco-nelson`
2. Subí todos los archivos de esta carpeta
3. Anda a Settings > Pages > Source: Deploy from a branch > main / root
4. Tu app va a estar en https://tu-usuario.github.io/kiosco-nelson/

O abrí `index.html` local con Chrome.

## Instalación como App en el celu
Chrome > 3 puntitos > Agregar a pantalla de inicio / Instalar app
